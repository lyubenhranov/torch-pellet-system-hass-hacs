# Integrate your Torch Pellet System in Home Assistant

## How to connect
1. Login to https://my.torch.bg
2. Navigate to https://my.torch.bg/devices and click on the device you wish to connect
3. Copy the id of the device from the URL (i.e. /devices/**88c33096-d2ec-4d5c-b5b2-07295348abb8**)

You now have all the information to setup the integration in Home Assistant.
